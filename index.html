01 / Guia de produto

Cera Matte

O acabamento discreto para um estilo com textura e personalidade.

Como aplicar

  1. Começa com uma quantidade pequena.
  2. Espalha o produto entre as palmas das mãos.
  3. Distribui pelo cabelo e modela com os dedos.
  4. Adiciona mais produto apenas se necessário.

Guia ilustrativo. As instruções finais serão ajustadas à fórmula do produto.

02 / Guia de produto

Cera com Brilho

Um visual mais polido, com acabamento luminoso e penteado definido.

Como aplicar

  1. Retira uma pequena quantidade de cera.
  2. Espalha uniformemente nas mãos.
  3. Aplica pelo cabelo de forma gradual.
  4. Finaliza com as mãos ou pente para definir o estilo.

Guia ilustrativo. As instruções finais serão ajustadas à fórmula do produto.
